# AVESTA

Сайт для астролога-консультанта, розроблений на Next.js та TypeScript.

Проєкт створений для реального клієнта та використовується як робочий сайт.

## Сайт

https://www.avestan.com.ua/

## Можливості

Адаптивний дизайн
Інформація про послуги та консультації
Каталог курсів
Форма зворотного зв'язку
Надсилання заявок у Telegram
Онлайн-оплата курсів через Monobank
Перевірка статусу оплати
Сповіщення про замовлення в Telegram

## Технології

Next.js
React
TypeScript
CSS
Monobank API
Telegram Bot API
Vercel

## Запуск проєкту

Встановити залежності:

```bash
npm install
```

Створити файл `.env.local` та додати необхідні змінні середовища.

Запустити проєкт:

```bash
npm run dev
```

Відкрити:

```text
http://localhost:3000
```
